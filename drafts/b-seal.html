Method

Probe, trace, tune, echo.

Every engagement follows the same four movements, whether we are building the system or teaching your team to build it.

One

Probe

Learn how the work actually happens. We start from your real structure and invent only the sensitive particulars.

Two

Trace

Write the plan as the record. Goals, assumptions, open questions, and a decision log in a plain file everyone can read.

Three

Tune

Build demo-first. Seeded data, role switching, and a ten-minute walkthrough for the decision-maker, then adjust against real use.

Four

Echo

Ship a system that reflects the mission. Every figure shows its arithmetic, every page is accessible, and the code stays open.

House style

What you can expect from any Tuned Echo build.

  • Real structure, invented particulars.You see your own institution in the first demo. Nothing sensitive is ever loaded.
  • Show the arithmetic.Budgets, roll-ups, and audit logs explain where every number came from.
  • Demo-first.Every build ships with seeded data, role switching, and a scripted walkthrough.
  • Open by default.MIT licenses. JSON, Markdown, and git rather than lock-in.
  • Small, boring stacks.Proven tools, self-hosted or static, that your staff can maintain.
  • AI-assisted, human-directed.Built with AI coding tools under expert direction. We teach the method too.

Working examples

Prototypes that show the institution to itself.

Each example is a working system with seeded demo data, role switching for live walkthroughs, and a scripted ten-minute demo for a named decision-maker.

Higher education

Assessment Hub

Institution-wide learning outcomes assessment: curriculum maps with live gap warnings, annual reports with review workflow, and a printable accreditation evidence summary.

Higher education

Academic Budget Hub

Department, school, and institution budgets with the arithmetic behind every figure, plus a policy lab for comparing budget models before adopting them.

Higher education

Teaching Observation Hub

Peer teaching observations for an entire college: automatic pairings from the term schedule, forms, acknowledgments, and completion tracking.

Publishing

Proceedings Desk

A submission and tracking system for conference proceedings, designed to replace a vendor platform with fewer screens, bulk actions, and integrity checks before publication.

Research

Semantic Librarian

A meaning-based search library built from any document set. Documents, authors, and years share one semantic space, exported as a static web app.

Research

Open Typing Science Project

A citizen-science platform that collects keystroke data to test practice schedules, planned with consent, data governance, and pre-registered analysis built in.

Built from inside the institution.

Tuned Echo Systems is led by Matt Crump, a cognitive psychologist who studies memory, learning, and skilled performance. He is a professor and chair of Psychology at Brooklyn College, CUNY, and has built open software for academic work since 2012: R packages, open textbooks, web-based experiments, and department tools.

He runs an academic department, so he knows the problems of budgets, assessment, personnel review, and accreditation from the inside rather than as a vendor. Tuned Echo builds with AI coding tools under human direction, which is why prototypes arrive in weeks rather than months, and it teaches that method to clients.
