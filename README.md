# tunedecho.github.io

Website for Tuned Echo Systems LLC. "We tune your systems until they echo your mission."

## Status

Drafting. Three design variations live in `drafts/`:

- `drafts/a-letterhead.html`: cream page, wordmark-first, the seven bars as section rules.
- `drafts/b-seal.html`: ink hero carrying the seal, bordered blocks, one brand color per section.
- `drafts/c-signal.html`: the motto as the hero, hairline grid, condensed labels from the seal.

Each file is self-contained. Open it in a browser to review.

## Assets

- `assets/seal.svg`: the seal, redrawn as vector art so it stays crisp and takes the page's text color.
- `assets/reference-wordmark.png`, `assets/reference-seal.png`: the original logo concepts.

## Publishing

Once a variation is chosen it becomes `index.html` at the root and a GitHub Actions workflow deploys the site to GitHub Pages on every push to `main`.
